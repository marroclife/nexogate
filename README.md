# NEXO Gateway

App web mobile-first para exploração do Project Gateway (CIA/Monroe) com player binaural, protocolos, teoria e registro de sessões.

## 🌐 URLs

- **Vercel (oficial):** https://nexogate.vercel.app
- **Repositório:** https://github.com/marroclife/nexogate
- **GitHub Pages (mirror):** https://marroclife.github.io/nexogate/

## 📱 Funcionalidades

- Player binaural via Web Audio API (F10, F12, F15, F21, F27)
- Timer de sessão com presets
- Navegação por abas mobile-first
- Registro de sessões com localStorage
- Checklist de segurança
- PWA básico (manifest + service worker)

## 🚀 Deploy

O site é estático. Para deploy na Vercel:

```bash
npx vercel --prod
```

Para GitHub Pages, o conteúdo da branch `main` na raiz já está servindo.
